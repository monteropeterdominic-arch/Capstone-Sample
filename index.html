How the analysis works

Two OLS models share eight explanatory variables: maximum temperature, relative humidity, wind speed, rainfall, distance to road, distance to river, distance to irrigation, and elevation.

  • Model 1: percentage of area affected by E. carotovora (severity).
  • Model 2: frequency of disease incidence (number of cases).

Data were natural-log (ln) transformed in SPSS, and outliers were removed using box plots.

Supporting methods

  • Kernel density: hotspot map of where cases concentrate (mapping step, not part of the regression).
  • Near tool: distance from each record to the nearest road, river, irrigation line and elevation contour.
  • Moran's I: checks if variables are clustered or random. Distance to road and elevation first showed clustering.
  • R² / Adjusted R²: model fit.
  • VIF: redundancy check, all below 7.5.
  • Joint F-statistic: overall model significance.
  • Koenker (BP): tests if relationships stay consistent across space. Not significant, so GWR was not needed.

About this sample

Boundaries: PSGC municipal boundaries (faeldon/philippines-json-maps). Rivers and irrigation canals: HOTOSM Philippines waterways. Roads: OpenStreetMap. Elevation: ALOS AW3D30. All were processed in QGIS. The disease points, climate values and OLS numbers are placeholders (OLS values from Idris et al., 2023, Johor) and must be replaced with the capstone data.
